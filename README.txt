PYTHON DATA ANALYSIS EXPERIMENTS: 1, 3, 5, 7, 8, 9, 10
======================================================

Each experiment includes a Python program and its own useful sample CSV dataset.

1. Subject-wise Average Score Analysis Using NumPy Arrays
   Files: 1_experiment.py, 1_subject_scores.csv

3. Average Sale Price of Houses with More Than Four Bedrooms Using NumPy
   Files: 3_experiment.py, 3_house_prices.csv

5. Average Fuel Efficiency and Percentage Improvement Between Car Models Using NumPy
   Files: 5_experiment.py, 5_car_fuel_efficiency.csv

7. Customer Order Analysis Using Pandas DataFrame
   Files: 7_experiment.py, 7_customer_orders.csv

8. Top 5 Best-Selling Products Using Pandas
   Files: 8_experiment.py, 8_best_selling_products.csv

9. Property Data Analysis Using Pandas DataFrame
   Files: 9_experiment.py, 9_property_data.csv

10. Line Plot and Bar Plot of Monthly Sales Data Using Matplotlib
    Files: 10_experiment.py, 10_monthly_sales.csv

Requirements
------------
Python 3.9+
Install libraries:
    pip install numpy pandas matplotlib

How to run
----------
Extract this ZIP, open a terminal in the extracted folder, and run:
    python 1_experiment.py
    python 3_experiment.py
    python 5_experiment.py
    python 7_experiment.py
    python 8_experiment.py
    python 9_experiment.py
    python 10_experiment.py

Experiment 10 saves its charts as PNG files in the same folder.
All datasets are illustrative practice data created for these experiments.
